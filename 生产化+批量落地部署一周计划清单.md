# One-Week Production Batch Landing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a directly deployable MF Monitor release in one week, excluding only real camera hardware, with a production-ready platform baseline, 10-device Jetson templating, and repeatable fleet rehearsal.

**Architecture:** Keep the existing HA platform topology (`backend_api_1` / `backend_api_2` / `backend_worker` / `mysql` / `mysql_replica` / `mqtt_primary` / `mqtt_secondary` / `nginx`) and avoid large refactors. Add an inventory-driven deployment layer above the current backend and Jetson code so platform bootstrap, Jetson config generation, and 10-device rehearsal all come from the same source of truth.

**Tech Stack:** FastAPI, SQLAlchemy, MySQL 8, Mosquitto, HAProxy, Nginx, PowerShell, Bash, systemd, C++17, OpenCV, TensorRT, Vue 3, Docker Compose

Create `scripts/bootstrap_devices_from_inventory.ps1` using the existing device API:

```powershell
Param(
  [string]$InventoryFile = ".\deploy\inventory\devices.csv",
  [string]$BaseUrl = "https://127.0.0.1",
  [string]$ApiKey
)

$ErrorActionPreference = "Stop"
$rows = Import-Csv $InventoryFile
$headers = @{ Authorization = "Bearer $ApiKey" }

foreach ($row in $rows) {
  $payload = @{
    aibox_id = $row.aibox_id
    cam_id = $row.cam_id
    device_name = $row.device_name
    device_type = "monitor_node"
    enabled = [bool]::Parse($row.enabled)
    allow_config_push = $true
    allow_remote_control = $false
    metadata_json = @{
      site_code = $row.site_code
      video_source = $row.video_source
    }
    location = $row.location
    latitude = [double]$row.latitude
    longitude = [double]$row.longitude
  }

  Invoke-RestMethod "$BaseUrl/api/devices" -Method Post -Headers $headers -Body ($payload | ConvertTo-Json -Depth 6) -ContentType "application/json"
}
```

```powershell
Param(
  [string]$InventoryFile = ".\deploy\inventory\devices.csv",
  [string]$TemplateFile = ".\jetson_edge_disnet_cpp\configs\templates\device.ini.template",
  [string]$OutputRoot = ".\artifacts\jetson-sites",
  [string]$EnginePath = "/home/nvidia/mudflow_project/model_onnx/EdgeDisNet_fp16_jetson.engine",
  [string]$EvidenceUploadApiKey
)

$rows = Import-Csv $InventoryFile
$template = Get-Content $TemplateFile -Raw -Encoding UTF8

foreach ($row in $rows) {
  $siteDir = Join-Path $OutputRoot $row.site_code
  $configDir = Join-Path $siteDir "config"
  New-Item -ItemType Directory -Force -Path $configDir | Out-Null

  $content = $template `
    .Replace("{{AIBOX_ID}}", $row.aibox_id) `
    .Replace("{{CAM_ID}}", $row.cam_id) `
    .Replace("{{VIDEO_SOURCE}}", $row.video_source) `
    .Replace("{{ENGINE_PATH}}", $EnginePath) `
    .Replace("{{MQTT_HOST}}", $row.mqtt_host) `
    .Replace("{{MQTT_PORT}}", $row.mqtt_port) `
    .Replace("{{EVIDENCE_UPLOAD_URL}}", $row.evidence_upload_url) `
    .Replace("{{EVIDENCE_UPLOAD_API_KEY}}", $EvidenceUploadApiKey)

  Set-Content -Path (Join-Path $configDir "device.ini") -Value $content -Encoding UTF8
}
```
